# Public Portfolio Scope and Disclosure

## Purpose

This repository is a public portfolio describing practical work across Shopify, React-powered storefronts, product information systems, commercial UX, form integrations, quality assurance, and production recovery.

## Included

The repository includes a public site preview, sanitized case studies, implementation themes, and high-level descriptions of validation and deployment practices.

## Excluded

The repository excludes proprietary sell sheets, private customer data, pricing files, full production bundles, source code belonging to a client or employer, Shopify access tokens, GitHub tokens, Formspree credentials, cookies, `.env` files, private URLs, internal screenshots, and browser session data.

## Attribution and authorization

The repository describes contributions made to a commercial storefront and is not presented as an ownership claim over the underlying brand, product documents, or client code. The portfolio is intentionally limited to work themes, technical methods, and outcomes that are appropriate for public professional review.

## Reproducibility

The private companion repository contains the operational backup. This public repository is not intended to be used to deploy the commercial site. It should be treated as a portfolio and case-study repository, not as production source code.
